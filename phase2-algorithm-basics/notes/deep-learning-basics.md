# 深度学习基础概念

## 机器学习 vs 深度学习

### 机器学习（Machine Learning）

机器学习的核心范式: **从数据中学习映射关系 $f: X \rightarrow Y$，而非手工编写规则**。

**三种学习范式**:

| 范式 | 数据形式 | 目标 | 例子 |
|------|---------|------|------|
| **监督学习** | $(x_i, y_i)$ 带标签 | 学习 $x \rightarrow y$ 的映射 | 分类、回归 |
| **无监督学习** | $x_i$ 无标签 | 发现数据内在结构 | 聚类、降维、生成 |
| **强化学习** | $(s, a, r, s')$ 交互序列 | 学习最大化累积奖励的策略 | 游戏 AI、机器人控制 |

**传统 ML 的关键瓶颈**: 模型性能上限很大程度上由**特征工程的质量**决定。对于图像，需要专家设计 SIFT/HOG 特征；对于文本，需要设计 TF-IDF/词袋特征。深度学习的革命性在于打破了这一瓶颈。

### 深度学习（Deep Learning）

深度学习的本质是**用多层非线性变换自动学习层次化表示**:

$$f(x) = f^{(L)} \circ f^{(L-1)} \circ ... \circ f^{(1)}(x)$$

每一层 $f^{(l)}(x) = \sigma(W^{(l)}x + b^{(l)})$ 学习一种表示变换。

**层次化特征学习示例**（以人脸识别为例）:

| 层 | 学到的特征 |
|----|-----------|
| Layer 1 | 边缘、颜色斑块 |
| Layer 2 | 角点、简单纹理 |
| Layer 3 | 眼睛/鼻子/嘴巴的局部形状 |
| Layer 4-5 | 完整面部结构 |
| Layer 6+ | 身份、表情等高层语义 |

**为什么"深"很重要**: 深层网络的表示能力随深度指数增长。一个 $n$ 层的 ReLU 网络可以将输入空间划分为 $O(2^n)$ 个线性区域。

## 前向传播与反向传播

### 前向传播

$$z^{(l)} = W^{(l)}a^{(l-1)} + b^{(l)}$$
$$a^{(l)} = \sigma(z^{(l)})$$

其中 $a^{(0)} = x$（输入），$a^{(L)} = \hat{y}$（输出）。

**直觉理解**: 前向传播就是**一层层地对输入做变换**。可以把每一层想象成一个"加工站":
- 全连接层: 对输入做线性组合 + 平移
- 激活函数: 引入非线性（否则多层等价于一层）
- 池化层: 降采样，增加平移不变性
- 归一化层: 保持数值稳定

### 反向传播

反向传播不是单独的前向或反向——它是**一次前向 + 一次反向**的组合:

1. **前向**: 计算每层的 $z^{(l)}$ 和 $a^{(l)}$，缓存中间值
2. **损失计算**: $L = \text{loss}(\hat{y}, y)$
3. **反向**: 从输出层开始，逐层计算 $\frac{\partial L}{\partial W^{(l)}}$ 和 $\frac{\partial L}{\partial b^{(l)}}$

**链式法则的核心**:

$$\frac{\partial L}{\partial W^{(l)}} = \frac{\partial L}{\partial z^{(l)}} \cdot \frac{\partial z^{(l)}}{\partial W^{(l)}} = \delta^{(l)} \cdot (a^{(l-1)})^T$$

其中 $\delta^{(l)} = \frac{\partial L}{\partial z^{(l)}}$ 是第 $l$ 层的**误差信号**，通过递推计算:

$$\delta^{(l)} = (W^{(l+1)})^T \delta^{(l+1)} \odot \sigma'(z^{(l)})$$

**为什么反向传播是高效的**: 计算 $\delta^{(l)}$ 需要 $\delta^{(l+1)}$，所以从后往前一次遍历即可得到所有梯度——时间复杂度 $O(n)$，空间复杂度 $O(n)$。

**实际例子（手工计算一个简单网络）**:

一个两层的网络，初始权重 $w_1 = 2$, $w_2 = 1$，学习率 $\eta = 0.1$，输入 $x = 1$，标签 $y = 0.5$（无偏置）

- Layer 1: $z_1 = w_1 x = 2 \cdot 1 = 2$, $a_1 = \text{sigmoid}(2) \approx 0.88$
- Layer 2: $z_2 = w_2 a_1 = 1 \cdot 0.88 = 0.88$, $\hat{y} = \text{sigmoid}(0.88) \approx 0.71$
- Loss: $L = \frac{1}{2}(0.71 - 0.5)^2 \approx 0.022$

反向:

$$\frac{\partial L}{\partial \hat{y}} = 0.71 - 0.5 = 0.21$$
$$\frac{\partial L}{\partial w_2} = 0.21 \cdot 0.71(1-0.71) \cdot 0.88 \approx 0.038$$
$$\frac{\partial L}{\partial w_1} = 0.21 \cdot 0.71(1-0.71) \cdot 1 \cdot 0.88(1-0.88) \cdot 1 \approx 0.0046$$

更新:
$$w_2 \leftarrow 1 - 0.1 \cdot 0.038 = 0.996$$
$$w_1 \leftarrow 2 - 0.1 \cdot 0.0046 = 1.9995$$

## 损失函数

### 常见损失函数

| 损失函数 | 公式 | 适用场景 |
|----------|------|----------|
| MSE | $$\frac{1}{n}\sum(y_i - \hat{y}_i)^2$$ | 回归 |
| MAE | $$\frac{1}{n}\sum\|y_i - \hat{y}_i\|$$ | 回归（抗异常值） |
| Cross-Entropy | $$-\sum y_i \log(\hat{y}_i)$$ | 分类 |
| Binary Cross-Entropy | $$-[y\log(\hat{y}) + (1-y)\log(1-\hat{y})]$$ | 二分类 |
| Hinge Loss | $$\max(0, 1 - y\hat{y})$$ | SVM 分类 |
| Huber Loss | 结合 MSE 和 MAE | 回归（抗异常值 + 可导） |
| KL Divergence | $$\sum p(x)\log\frac{p(x)}{q(x)}$$ | 分布匹配、变分推断 |

### 损失函数选择指南

```
任务是分类？
├── 二分类 → Binary Cross-Entropy + Sigmoid
└── 多分类 → Cross-Entropy + Softmax

任务是回归？
├── 数据干净 → MSE
├── 可能有异常值 → Huber Loss
└── 异常值很多 → MAE

任务是生成？
├── 图像生成 → Adversarial Loss + Perceptual Loss
└── 文本生成 → Cross-Entropy（自回归）

多任务？
→ 加权求和: L_total = λ₁L₁ + λ₂L₂ + ...
```

### 损失函数与梯度的关系

梯度 $\nabla L$ 是参数更新的唯一依据。损失函数的形状直接影响优化的难易程度:

- **MSE 损失景观**: 凸且光滑，梯度随误差线性减小 → 接近最优时更新步长变小（需要调整学习率）
- **Cross-Entropy 损失景观**: 非凸但梯度信号强 → 模型自信地犯错时仍有大梯度（适合分类）

## 梯度消失与梯度爆炸

### 问题根源

深层网络中，梯度通过连乘传播:

$$\frac{\partial L}{\partial W^{(1)}} \propto \prod_{k=2}^{L} \frac{\partial a^{(k)}}{\partial a^{(k-1)}}$$

每一项 $\frac{\partial a^{(k)}}{\partial a^{(k-1)}}$ 的大小决定了梯度的缩放:

- 如果 $< 1$ 的项占多数: 梯度**消失**
- 如果 $> 1$ 的项占多数: 梯度**爆炸**

### 具体触发条件

| 原因 | 导致 | 机制 |
|------|------|------|
| Sigmoid/Tanh 饱和 | 梯度消失 | $\sigma'(x)$ 在 $\|x\|$ 大时 → 0 |
| 权重初始化过大 | 梯度爆炸 | $W$ 的谱范数 > 1 |
| 权重初始化过小 | 梯度消失 | $W$ 的谱范数 < 1 |
| 网络过深 | 两者 | 微小偏差被指数放大/缩小 |

### 各解决方案的直观解释

| 方法 | 为什么有效 |
|------|-----------|
| **ReLU** | 正半轴导数为 1（完美梯度传输），负半轴导数为 0（稀疏激活） |
| **Xavier/He 初始化** | 数学推导保证前向方差 = 反向方差，梯度尺度稳定 |
| **Batch Norm** | 将激活值强制拉回激活函数的非饱和区 |
| **Residual** | 提供"梯度高速公路"——$\frac{\partial (F(x)+x)}{\partial x} = \frac{\partial F(x)}{\partial x} + 1$，恒等映射保证至少为 1 的梯度 |
| **Gradient Clipping** | 简单粗暴但有效——梯度太大就按比例缩小 |

### 实践中的优先级

```
1. 使用 ReLU（或 GELU）+ He 初始化 → 解决大部分问题
2. 网络 > 10 层 → 加 Batch/Layer Norm
3. 网络 > 50 层 → 加残差连接
4. 训练 RNN/Transformer → 加梯度裁剪
```

## 深度学习算法设计思路

### 标准设计流程

```
┌──────────────────────────────────────────────────┐
│  1. 明确问题: 输入 X → 输出 Y，评估指标 M          │
│  2. 准备数据: 收集 → 清洗 → 增强 → 划分 → 标准化    │
│  3. 选架构: MLP / CNN / RNN / Transformer          │
│  4. 定损失: MSE / CrossEntropy / ...              │
│  5. 选优化器: Adam / SGD / ...                    │
│  6. 训练: for epoch in range(N): ...              │
│  7. 调参: 学习率、batch size、层数、...             │
│  8. 评估: 测试集 + 可视化                          │
└──────────────────────────────────────────────────┘
```

### 设计决策树

```
数据量？
├── < 1000 → 传统 ML（RF, SVM）可能更好
├── 1000-10000 → 小网络 + 强正则化 + 数据增强
└── > 10000 → 深度学习

数据类型？
├── 图像 → CNN / ViT
├── 文本/序列 → Transformer / LSTM
├── 表格 → MLP / Gradient Boosting
└── 多模态 → 多塔架构 + 融合层

计算资源？
├── 单 GPU → 小 batch + 梯度累积 + 混合精度
├── 多 GPU → 数据并行 (DistributedDataParallel)
└── 无 GPU → 减小模型或使用预训练模型
```

### "基线优先"原则

不要一上来就建大模型。正确顺序:

1. **建立简单基线**（如线性模型 / 小 MLP）→ 确定问题可学
2. **逐步加复杂度**（加深、加宽、换架构）→ 观察验证指标是否提升
3. **每次只改一个变量** → 明确知道什么起作用
4. **不过度优化验证集** → 保留测试集做最终评估
