# ACT 论文阅读笔记

> 论文: *Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware*  
> Zhao, Kumar, Levine, Finn · RSS 2023  
> 链接: https://arxiv.org/abs/2304.13705  
> 项目: https://tonyzhaozh.github.io/aloha/

## 核心贡献

1. **ALOHA 硬件系统**: 总成本不到 $20k 的低成本开源双手遥操作平台——两个 ViperX 300 从臂 + 两个 WidowX 250 主臂 + 4 个 webcam + 3D 打印组件
2. **ACT 算法**: Action Chunking with Transformers——用 CVAE + Transformer 一次预测未来 $k$ 步动作（chunk），大幅降低复合误差
3. **只用 ~10 分钟（~50 条）演示数据**，在 6 个高难度真实任务上达到 80-90% 成功率

## 要解决的问题

**细粒度双手操作（fine-grained bimanual manipulation）**——传统方案依赖昂贵硬件 + 精密传感器 + 精确标定。而标准模仿学习（逐帧预测动作）在长时序任务中会出现：
- **复合误差（compounding errors）**: 小预测误差逐步累积，机器人越来越偏离训练分布
- **时间不连贯**: 逐帧输出 = 抖动，特别是接触密集任务
- **演示中的停顿**: 人类操作员可以停顿，策略不应把"停顿"当作必须模仿的行为

## 方法概述

### Action Chunking

核心思想：**一次预测一段（chunk），而不是一帧**。

传统模仿学习每一步预测一个动作 $a_t$:
$$\pi_\theta(s_t) \rightarrow a_t$$

ACT 每一步预测一个长度为 $k$ 的动作序列:
$$\pi_\theta(s_t) \rightarrow \{a_t, a_{t+1}, ..., a_{t+k-1}\}$$

**为什么有效**:
- **降低有效控制频率**: $k$ 步中只需推理一次，控制周期不变
- **减少复合误差**: 轨迹分 $k$ 段而不是逐帧
- **建模动作连贯性**: chunked action 天然捕捉运动模式
- **处理停顿**: 人类演示中的"停顿"自然成为 chunk 内的一段"不动"，不需要特别处理

### 为什么需要 $k=100$（2 秒的轨迹）

- 50Hz 控制频率下，$k=100$ 覆盖 2 秒运动
- 2 秒是大多数手工操作动作的自然时长（抓取、移动、放置）
- 太短 → 复合误差仍然严重
- 太长 → 难以学习（轨迹多样性淹没模式）

## 网络结构

```
输入: 4 路 RGB (480×640) + 14 维关节位置(双臂各7维)
         │                              │
         ▼                              ▼
  ┌──────────────┐                Joint Encoder
  │ResNet-18 × 4 │                  (线性层)
  │共享权重       │                    │
  └──────┬───────┘                    │
         │ 4 × 512-d                  │ 14 → 512-d
         └────────┬───────────────────┘
                  ▼
          Transformer Encoder
        (4 layers, 8 heads, dim 512)
                  │
     ┌────────────┼────────────┐
     ▼            ▼            ▼
  [CLS]      Visual Tokens   Joint Tokens
     │
     ▼
  ┌──────────────────────────────┐
  │ CVAE Encoder                 │
  │ action sequence + joint      │──→ z (32-d latent, 训练时用, 推理时 = 0)
  │ → μ, σ → reparameterize     │
  └──────────────────────────────┘
     │
     ▼
  ┌──────────────────────────────┐
  │ Transformer Decoder          │
  │ 自回归生成 k 个 target joint │
  │ positions (14-d each)        │
  └──────────────────────────────┘
```

### CVAE 的作用

ACT 是一个**条件变分自编码器**（CVAE）:

- **Encoder**($q_\phi(z \mid a, o)$): 观察整个动作序列 $a$ + 关节观测 $o$ → 编码为 32 维 latent $z$
  - $z$ 捕获演示中的"风格差异"（快/慢、直/弯、不同操作员）
- **Decoder/Policy**($\pi_\theta(a \mid o, z)$): 给定观测 $o$ 和风格 $z$ → 生成动作序列
  
**关键设计**: 推理时 $z$ 设为全零向量——这样就只学"均值"风格，不受特定演示员影响。这也是为什么需要 CVAE 而不是普通 autoregressive: 没有 CVAE，模型会把演示中的风格差异当噪音，训练不稳定。

### Temporal Ensemble（时序集成）

策略以 $f$ Hz 运行推理，但执行以 $f'$ Hz 更高速率。多个预测 chunk 的**重叠部分取加权平均**:

$$\hat{a}_t = \sum_i w_i \cdot a_t^{(i)}$$

其中 $a_t^{(i)}$ 是第 $i$ 个 chunk 中对应时间步 $t$ 的预测。$w_i$ 是权重（近当前时刻权重大、远时刻权重小）。

**效果**: 极大提升动作平滑度（消除高频抖动），论文里这个技巧贡献了显著的成功率提升。

### 训练细节

| 参数 | 值 |
|------|-----|
| 优化器 | AdamW |
| 学习率 | $10^{-5}$ |
| Chunk size $k$ | 100 (2 秒 @ 50Hz) |
| KL weight $\beta$ | 10 |
| Hidden dim | 512 |
| Feedforward dim | 3200 |
| Encoder layers | 4 |
| Decoder layers | 7 |
| Attention heads | 8 |
| Batch size | 8 |
| Epochs | 2000 |
| GPU | RTX 3090 × 1 |
| 训练时间 | ~2-4 小时（每个任务 ~50 条演示） |

### 动作空间

ACT 输出的是**关节空间**的目标位置——不是 EEF 位姿：
- 双臂各 7 维（6 个关节角 + 1 个夹爪），共 14 维
- 走关节空间 = 不需要 IK 求解器 = 训练更简单、无奇异点问题
- ALOHA 的 PID 控制器直接跟踪这些目标关节位置

## 实验结果

### 真实环境任务（6 个）

| 任务 | 演示数 | 成功率 | 特点 |
|------|:--:|:--:|------|
| 转移方块 | 50 | **~95%** | 基础抓取+放置 |
| 打开调味杯 | 50 | **~85%** | 半透明物体、需要精细力控 |
| 插入电池 | 50 | **~80%** | 高精度插座对接 |
| 拧开瓶盖 | 50 | ~75% | 旋转 + 保持抓取稳定 |
| 穿绑线 | 50 | ~75% | 极高精度末端对齐 |
| 乒乓颠球 | 50 | ~70% | 动态任务、需要时间协调 |

### 消融实验

| 变体 | 转移方块成功率 | 说明 |
|------|:--:|------|
| ACT (完整) | **~95%** | |
| 无 CVAE | ~85% | 风格变量消失 → 训练不稳定 |
| chunk=1（逐帧） | ~45% | 复合误差严重 |
| 无 temporal ensemble | ~80% | 动作不够平滑 |
| 单相机 | ~75% | 多视角对精细操作很重要 |

## 与 ALOHA 硬件的关系

- 硬件决定了动作空间：**关节空间控制**（因为主从遥操作直接映射关节角度，不需要 IK）
- 关节空间的遥操作 = **反向驱动（backdriving）**：人移动主臂 → 关节编码器读数 → 直接复制给从臂
- 这种设计的优点：不需要力传感器，PID 的跟踪误差隐含了力信息（碰到东西 → 角度偏差增大 → 控制扭矩增大）

## 对后续 Phase 4/5 的影响

1. ACT 的输出是**关节空间而非 EEF**——与 VLA 综述中大多数模型不同（我们在 Phase 3 笔记中已修正这一点）
2. ACT **没有语言编码器**——是纯视觉-运动策略，由任务切换驱动（同一算法训多个任务）
3. Chunk size $k$ 是核心超参数——Phase 5 的 Mole-VLA 也有类似的时间集成概念
