# ALOHA 操作指南

> 设备: ALOHA (A Low-cost Open-source Hardware system for Bimanual Teleoperation)  
> 原论文: https://tonyzhaozh.github.io/aloha/  
> 国内替代: 松灵 Cobot Magic / 松灵分体式 ALOHA

### 主从映射原理

```
人移动主臂 → 主臂关节编码器读取 q_leader → 直接赋值 q_follower = q_leader → PID 跟踪
```

这种关节空间直接映射的优点是：
- **不需要逆运动学**（IK），无奇异点问题
- **高带宽**（50Hz 以上），延迟低
- **隐含力信息**: PID 跟踪误差 ≈ 力的测量（碰到障碍 → 角度偏差大 → 控制扭矩增大）
- **训练简单**: 演示数据完全在关节空间，ACT 直接学"给定图像 → 输出关节角度"

## 基本操作流程

### 1. 系统上电

```
启动底盘 → 主臂/从臂上电 → 工控机启动 → 检查各关节零位
```

### 2. 主从校准

主臂和从臂的关节零位必须对齐：
- 机械调零（物理对齐各关节）
- 软件校准（捕获关节偏移量）
- 测试：缓慢移动主臂，观察从臂是否同步跟随

### 3. 数据采集

每个演示片段保存为 HDF5 文件:

```
episode_0.hdf5
├── /observations/images/top         # 顶部相机 (480×640×3)
├── /observations/images/left_wrist  # 左腕相机
├── /observations/images/right_wrist # 右腕相机
├── /observations/images/front       # 前方相机
├── /observations/qpos               # 14 维关节位置 (双臂各 7)
└── /action                          # 14 维目标关节位置
```

每个任务采集 **50 条演示**（~10 分钟操作时间），覆盖任务的自然变体（不同起始位置、不同朝向）。

### 4. ACT 训练

```bash
# 官方 repo (tonyzhaozh/aloha)
python imitate_episodes.py \
  --task_name <task_name> \
  --policy_class ACT \
  --kl_weight 10 \
  --chunk_size 100 \
  --hidden_dim 512 \
  --batch_size 8 \
  --dim_feedforward 3200 \
  --num_epochs 2000 \
  --lr 1e-5 \
  --seed 0
```

**训练耗时**: 50 条演示 + RTX 3090 = ~2-4 小时

### 5. 推理

```bash
# 加载训练好的模型，部署到真实机器人
python imitate_episodes.py ... --eval --temporal_agg
```

推理时 CVAE 的 $z$ 设为零 → 只学"均值风格"。`--temporal_agg` 开启时序集成（关键：动作平滑度大幅提升）。

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 主从延迟/不同步 | 网络延迟（WiFi 不可靠） | 使用有线以太网 / 本地环回 |
| 相机时间戳偏移 | 多相机时间不同步 | 软件层面做时间戳对齐 |
| 双臂碰撞 | 运动规划不当 | 限制主臂操作空间、加入臂间避碰规则 |
| 从臂抖动 | PID 增益过大 | 调低 $K_p$ 或加入低通滤波 |
| 夹爪抓不住 | 夹持力不足/表面太滑 | 换防滑胶带、调大夹持力 |
| 关机后零位丢失 | 断电后编码器失忆 | 每次开机重新机械调零 |

## 安全注意事项

1. 每次操作前检查急停按钮是否可用
2. 所有关节限位、速度/力上限必须硬编码（不依赖策略自身限制）
3. 首次执行新策略时，降低运行速度至 20-30%
4. 操作员应站在臂展范围外
5. 实验场地内无人时才能全速运行
