## 核心概念速查

| 术语 | 英文 | 解释 |
|------|------|------|
| 连杆 | Link | 机械臂的刚性构件，通过关节连接 |
| 关节 | Joint | 两个连杆之间的连接，提供运动自由度 |
| 旋转关节 | Revolute Joint | 产生相对旋转运动的关节 |
| 平移关节 | Prismatic Joint | 产生相对平移运动的关节 |
| 自由度 | DOF (Degree of Freedom) | 独立运动变量的数量，3D 空间中完整位姿控制需 6 DOF |
| 末端执行器 | End-effector | 执行任务的终端装置（夹爪、焊枪等） |
| 工作空间 | Workspace | 末端执行器能到达的空间区域 |
| 正向运动学 | Direct/Forward Kinematics | $q$（关节变量）→ $x_e$（末端位姿）的映射 |
| 逆运动学 | Inverse Kinematics | $x_e$（目标位姿）→ $q$（关节变量）的映射 |
| 雅可比矩阵 | Jacobian | 关节速度 → 末端速度的线性映射矩阵 |
| 运动学冗余 | Kinematic Redundancy | DOF 多于任务所需，存在无穷多解 |
| 奇异性 | Singularity | 雅可比矩阵秩下降，某些方向上失去运动能力 |
| 动力学 | Dynamics | 力/力矩与运动之间的关系 |
| DH 参数 | Denavit-Hartenberg Convention | 用 4 个参数（$a_i, d_i, \alpha_i, \vartheta_i$）描述相邻连杆坐标系变换的标准方法 |
| 关节空间 | Joint Space | 以关节变量 $q$ 为坐标的空间 |
| 操作空间 | Operational Space | 以末端执行器位姿 $x_e$ 为坐标的笛卡尔空间 |
| 本体感知 | Proprioceptive | 测量机器人内部状态（关节角度、速度）的传感器 |
| 外感知 | Exteroceptive | 测量环境状态的传感器（摄像头、力传感器） |
| 轨迹规划 | Trajectory Planning | 生成满足时空约束的运动参考轨迹 |
| 阻抗控制 | Impedance Control | 调节机器人表现出的力-位移关系（"硬度"） |
| 力控制 | Force Control | 精确控制与环境接触力 |
| 柔顺性 | Compliance | 对外力的顺应能力，分被动（机械）和主动（控制）两种 |
| 移动操作体 | Mobile Manipulator | 移动底盘 + 机械臂的组合系统 |
| 球形手腕 | Spherical Wrist | 三旋转轴交于一点的手腕，实现位置-姿态解耦 |
| 非完整约束 | Nonholonomic Constraint | 约束瞬时运动但不约束可达性的限制（如汽车不能横移） |
| 闭环运动链 | Closed Kinematic Chain | 连杆形成环路的运动链，刚度更高但工作空间更小 |
| 视觉伺服 | Visual Servoing | 用视觉反馈直接控制机器人运动 |

## 机器人系统的闭环结构

教材图 1.1 给出了机器人系统的基本架构——这是一个完整的**感知-决策-执行闭环**:

```
┌─────────────────────────────────────────────────────┐
│                    CONTROL SYSTEM                     │
│              (Task Planning + Control)                │
│         连接感知与行动的"智能"层                       │
└──────┬──────────────────────────────────┬────────────┘
       │ 指令                              │ 反馈
       ▼                                   ▲
┌──────────────┐                  ┌──────────────┐
│  ACTUATION   │                  │   SENSORY    │
│   SYSTEM     │──── 物理运动 ───▶│   SYSTEM     │
│ 伺服电机     │                  │ 编码器/相机   │
│ 减速器/传动  │                  │ 力传感器     │
└──────┬───────┘                  └──────┬───────┘
       │                                │
       ▼                                │
┌────────────────────────────────────────┴──┐
│           MECHANICAL SYSTEM               │
│      (连杆 + 关节 = 运动链 = 身体)         │
│              ⚡ 与物理世界交互              │
└───────────────────────────────────────────┘
```

**四个子系统的职责**:
1. **机械系统（Mechanical System）**: 物理本体——连杆和关节构成运动链
2. **执行系统（Actuation System）**: 伺服电机、驱动器、传动装置——将电信号转化为力/运动
3. **感知系统（Sensory System）**: 
   - **本体感知（Proprioceptive）**: 编码器（位置）、转速计（速度）、加速度计
   - **外感知（Exteroceptive）**: 摄像头、力/力矩传感器、激光雷达
4. **控制系统（Control System）**: 根据感知反馈 + 任务规划，计算控制指令，形成闭环

## 建模-规划-控制框架（核心方法论）

这是教材的核心范式，贯穿全书:

### 1. Modelling（建模）

建立机器人的数学模型:
- **运动学模型**（第 2-3 章）: 关节空间 ↔ 操作空间的映射，不考虑力
  - 正向: $x_e = k(q)$ — 给定关节角，末端在哪？
  - 逆: $q = k^{-1}(x_e)$ — 给定末端目标，关节怎么转？
  - 微分: $\dot{x}_e = J(q)\dot{q}$ — 关节速度如何影响末端速度
- **动力学模型**（第 7 章）: $$B(q)\ddot{q} + C(q,\dot{q})\dot{q} + g(q) = \tau$$ — 力如何驱动运动

### 2. Planning（规划）

生成参考运动（第 4、12 章）:
- **轨迹规划**: 在满足速度、加速度约束下，生成从起点到终点的平滑路径
- **任务规划**: 将高层任务目标（"抓取红色方块"）分解为机器人可执行的运动序列

### 3. Control（控制）

执行运动并处理不确定性（第 6、8、9 章）:
- **运动控制（Motion Control）**: 跟踪参考轨迹，如 PD + 重力补偿
- **力控制（Force Control）**: 调节接触力，如阻抗控制、混合力/位置控制
- **视觉伺服（Visual Servoing）**: 用视觉闭环驱动运动

## 机械臂构型分类

| 构型 | 关节类型（从基座起） | 工作空间形状 | 特点 |
|------|---------------------|-------------|------|
| **笛卡尔型（Cartesian）** | PPP | 长方体 | 精度最高，灵巧度最低，大尺寸物体 |
| **圆柱型（Cylindrical）** | RPP | 空心圆柱 | 刚度好，适合进入水平腔体 |
| **球型（Spherical）** | RRP | 空心球体 | 可覆盖基座下方空间，机床应用 |
| **SCARA** | RRP（轴平行） | 图 1.6 | 垂直刚度高、水平柔顺，适合垂直装配 |
| **拟人型（Anthropomorphic）** | RRR | 近似球体 | 最灵巧，工作空间体积最大，应用最广 (59%) |

## 关键收获

1. **机器人不是一个 API**，而是一个受物理定律约束的闭环系统。四个子系统（机械/执行/感知/控制）缺一不可。

2. **建模-规划-控制是思考一切机器人问题的基础框架**。即使使用深度学习方法，也要清楚你的 policy 输出的是什么物理量、输入包含哪些状态量、控制频率是多少。

3. **关节空间 vs 操作空间** 的选择贯穿始终。前者精确但直观性差，后者直观但需要逆运动学和奇异性处理。

4. **运动学冗余**（DOF > 任务所需）是双刃剑——更多灵活性但也带来更多决策复杂度。KUKA LWR 的 7 轴设计就是一例。

5. **力控制**是机器人与纯视觉 AI 的根本区别之一。抓取任务的核心不在于"看到物体"而在于"以恰当的力抓住它"。

6. **工业机器人（结构化环境）vs 先进机器人（非结构化环境）** 的区分很关键——具身智能要解决的是后者，即环境不确定、需要自主决策的场景。

## 与具身智能的关联思考

- **运动学模型 ↔ Policy 的动作空间设计**: 你是输出关节角度还是末端位姿？这直接对应于 joint space 还是 operational space 控制
- **动力学模型 ↔ 仿真环境**: MuJoCo、Isaac Gym 等仿真器本质上就是高效的动力学求解器
- **感知系统 ↔ Observation 设计**: 本体感知 + 外感知的多模态融合正是 VLA 模型需要处理的核心问题
- **控制闭环 ↔ 实时推理**: VLA 模型的推理速度必须匹配控制频率——这是 Transformer 大模型面临的工程挑战
- **轨迹规划 ↔ 模仿学习**: 人类遥操作演示的轨迹正是 planning 的结果，ACT 学习的就是这种轨迹生成能力
